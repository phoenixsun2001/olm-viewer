# OLM Viewer — Outlook for Mac 存档查看器

在本地浏览 Outlook for Mac 导出的 `.olm` 存档文件。单文件 Python 实现，零第三方依赖，数据不出本机。

## 特性

- **会话分组**（Outlook 风格）：同一回复链折叠为一条，显示计数与参与者，展开查看每封；跨文件夹的相关邮件灰显标注来源，可一键切换按时间平铺
- **全部邮件 / 全部附件**：跨文件夹浏览所有邮件；附件独立入口，按文件名 / 类型 / 来源邮件主题搜索，一键下载或预览
- **邮件阅读**：完整 HTML 正文（沙箱隔离渲染）、内嵌图片（cid）自动显示、收发件人与时间、附件下载
- **搜索与浏览**：主题 / 发件人 / 收件人 / 摘要过滤（文件夹内或全局）、时间正倒序、分页与页码跳转
- **其他数据**：联系人 / 日历 / 任务 / 便笺等 XML 条目的通用分页字段视图
- **高性能索引**：一次性扫描后持久化（SQLite），二次启动秒开；支持断点续扫，索引过程可随时中断

## 使用方法

```bat
python olm_viewer.py "路径\你的存档.olm"
```

| 参数 | 说明 |
|---|---|
| `--port N` | 指定端口（默认 8791） |
| `--no-browser` | 不自动打开浏览器 |
| `--reindex` | 丢弃已有索引并重建 |

启动后自动打开浏览器 `http://127.0.0.1:8791/`。首次使用会先建立索引（页面顶部显示进度，期间已扫到的内容即可浏览），完成后索引保存在 `olm_index/` 目录。

## 工作原理

`.olm` 是缺少中央目录的流式 ZIP64 容器（条目不压缩存储），标准 ZIP 工具无法打开。本工具通过链式解析 local file header 遍历全部条目（带断链自愈与断点续扫），分两阶段建立 SQLite 索引：

1. **条目扫描**：遍历容器内全部条目（邮件、附件、其他 XML），建立 名称 → 文件偏移 的映射；
2. **元数据索引**：解析每封邮件 XML，提取主题、发件人、时间、附件引用与会话线程键。

邮件正文与附件不缓存，阅读时按需从原文件读取，因此索引体积很小。

## 隐私与安全

- 服务仅监听本机 `127.0.0.1`，不暴露到局域网
- 索引与缓存全部保存在本机 `olm_index/` 目录，不向任何外部服务发送数据
- 邮件正文在 `sandbox` iframe 中渲染，脚本不执行
- XML 解析前拒绝 DTD / 实体声明，防实体扩展攻击

## 系统要求

- Python 3.8+（仅标准库，无需 pip 安装任何包）
- Windows / macOS / Linux 均可

## 常见问题

- **端口被占用**：换端口 `--port 8792`
- **索引损坏或想重建**：`--reindex`
- **移动项目目录**：索引按存档文件路径绑定，路径变化后需重新索引（或 `--reindex`）
